Website WhatsApp Chat Button

Add a customizable floating WhatsApp chat button to your website

Step 1 — Configuration

Go to Website → Configuration → Settings and find the WhatsApp section. Enter your phone number with country code and customize the button appearance.

Step 2 — Floating Button on Website

Once enabled, a beautiful floating WhatsApp button appears on all pages of your website. Visitors can click it to start a conversation with you directly on WhatsApp.

Features

✓ Click-to-chat — opens WhatsApp with a pre-filled message
✓ 5 positions — bottom-right, bottom-left, bottom-center, mid-right, mid-left
✓ 3 sizes — small, medium, large
✓ Custom color — pick any color with a color picker
✓ Pulse animation — attract attention with a subtle pulse effect
✓ Tooltip — customizable text with a close button
✓ Business hours — show only during configured work hours and days
✓ Multi-website — different settings per website
✓ Mobile responsive — adapts to mobile screens automatically
✓ Slide-in animation — smooth appearance on page load
